# Memorias

Memorias es el archivo editorial personal del portfolio. No se presenta como
un blog ni depende de publicar con una frecuencia artificial.

## Propósito

- Registrar decisiones técnicas con su contexto.
- Explicar aprendizajes, incluidos errores y dudas abiertas.
- Relacionar programación con producto, equipos, usuarios y oficio.
- Conservar evidencia útil para volver a pensar una idea con el tiempo.

## Líneas editoriales

1. **Sistemas**: arquitectura, rendimiento, datos, herramientas y decisiones.
2. **Oficio**: aprendizaje, depuración, procesos y criterio profesional.
3. **Relaciones**: producto, comunicación, equipos y experiencia de usuario.

## Forma de cada memoria

Cada entrada podrá contener:

- una fecha y un estado: `apunte`, `ensayo` o `retrospectiva`;
- una idea central breve;
- contexto y evidencia;
- código, imágenes o diagramas sólo cuando aporten claridad;
- lo que cambió después de escribirla;
- vínculos con otras memorias.

La siguiente iteración conectará esta pantalla con Nuxt Content para generar el
archivo, las páginas individuales y las relaciones entre entradas.
